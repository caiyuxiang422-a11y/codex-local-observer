# ADR 0012：白色液态玻璃与刘海紧凑排版修复

## 状态

已采用（2026-08-30）。

## 背景

实机截屏显示两个具体问题：

1. 硬件刘海收起宿主约为 417 × 32 AppKit 逻辑点，项目名的 flex 项被旧规则固定为 `flex: 0 0 auto`，长中文名称因此绘制到左侧芯片之外。
2. 收起态和展开态仍命中深色表面规则，与用户要求的苹果白色液态玻璃不一致；但真实摄像头缺口本身属于 macOS，应用不能把它涂白或伪造一个新的硬件刘海。

## 已核实事实

- AppKit 返回的是逻辑点，不是 Retina 截图像素；本机测得的宿主为 417 × 32 pt，中央间隙约 185 pt。
- 中央间隙的像素 alpha 为透明，黑色来自系统菜单栏/硬件区域；两侧芯片的深色像素来自应用 CSS。
- 完整项目名无法在约 104 pt 的紧凑侧轨中始终显示，因此必须采用省略号，并通过 title/无障碍标签保留完整名称。

## 决策

1. 在 CSS 文件末尾建立唯一的最终材质覆盖：浅色外观使用白色半透明液态玻璃，外层负责 blur 和深度，内部卡片使用较高不透明度的 tonal surface，不叠加第二层 blur；深色外观仍遵循系统配色。
2. 硬件收起态只绘制左右信息芯片，中心保持透明且点击穿透。芯片严格限制为可收缩的 flex/grid 项，并对标题、状态和指标应用 block-level ellipsis。
3. 当 AppKit 安全区小于 28 pt 时，紧凑态切换为单行密度，避免两行中文字形被父窗口裁掉；展开态不隐藏完整信息。
4. 无刘海回退的标题栏与父容器共享 inset 高度，避免 `margin-top` 后仍继承完整安全区而造成底部半像素溢出。
5. macOS 尺寸变化优先走 AppKit 单次 `setFrame`，前端只在非 AppKit 回退路径使用 Tauri 物理像素居中修正。屏幕几何刷新在 morph 期间只更新诊断数据，不抢占动画拥有的 frame。
6. 展开尺寸依据 AppKit visible frame 做上限裁剪；隐藏窗口时把指针采样从 120 ms 退避到 800 ms，减少无意义 IPC 和电量消耗。

7. 主窗口与快览窗口共用白色玻璃 token。只有外层功能表面使用 backdrop blur，内部信息卡片改为较高不透明度的 tonal surface；这是一种 WebView/CSS 的液态玻璃近似，不等同于原生 `NSVisualEffectView` 对窗口外桌面的取样。

8. widget 配置的最小尺寸降为 1pt，由 AppKit 几何和前端可读性规则决定实际尺寸。这样极窄虚拟屏不会被 Tauri 的固定 120×24pt 约束再次抬出屏幕；正常显示器仍使用 24–32pt 的安全区与芯片尺寸。

9. AppKit 宿主不再使用 `HUDWindow` style mask。该 mask 在部分 macOS 版本会强制深色 HUD 外观，与浅色白玻璃冲突；保留无边框、utility、non-activating panel 三项即可满足窗口几何和交互边界。

## 取舍与风险

- “白色”是浅色外观下的产品默认；系统深色外观仍显示深色材质，以保留系统一致性和可读性。若产品必须始终白色，应增加显式外观偏好，而不是暗中覆盖用户系统设置。
- 真实刘海中心仍会呈黑色，这是系统/硬件边界，不是本应用失败。应用不能控制摄像头切口，也不宣称拥有 BoringNotch 的私有能力。
- CSS 过渡用于离散的 hover/proximity 开关，能从当前呈现值重新定向；它不是带速度连续性的物理 spring。未来若加入持续拖拽或跟随指针，再引入 WAAPI/原生 spring，并先测量收益。
- 本轮采用了 Apple/Emil 原则中适用于“靠近展开”的子集（即时按下反馈、顶边空间锚定、可访问性回退、可中断的最新请求保护、材料层级和省略排版）；当前没有持续拖拽，因此没有虚构速度继承或弹簧手势能力。
- 当前本地 bundle 可以构建，但未签名/未公证的发行限制仍由 ADR 0011 负责；必须退出旧实例后启动新 bundle 才能看到本次 CSS。

## 验收

- 左右紧凑芯片的标题和指标 `getBoundingClientRect()` 不超出各自芯片边界；长名称显示省略号。
- 24、26、32、38 pt 高度下无半字；24–26 pt 使用单行密度。
- 浅色外观下展开面板和两侧芯片为白色玻璃，中心真实缺口保持透明；减少透明度/高对比度时退化为实色。
- `npm run check`、`cargo fmt --check`、`cargo test --lib`、`cargo clippy --all-targets -- -D warnings` 和 `npm run tauri:build` 均通过。
